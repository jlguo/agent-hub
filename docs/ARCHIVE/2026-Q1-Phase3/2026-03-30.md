## WebSocket Real-Time Updates Issue (DEBUGGING)

**Problem**: Web UI requires page refresh to see new messages from Feishu. WebSocket events not being received in real-time.

**Root Cause Identified**: Timing issue - WebSocket emits happen BEFORE client joins the room, or client disconnects/reconnects during emits.

**Evidence from Server Logs**:

```
✅ Feishu message saved
📡 About to emit to WebSocket, roomId: family-room-demo
📡 Got IO instance, emitting to room: family-room-demo
... (later) ...
✅ Client [id] joined room family-room-demo
```

**Debug Logging Added**:

- `MessageService.ts`: Added logs before WebSocket emit ("📡 About to emit", "📡 Got IO instance, emitting")
- `index.ts`: Enhanced room join log to "✅ Client [id] joined room [roomId]"

**Testing Protocol**:

1. Open Web UI (http://localhost:3000)
2. Wait for console logs in order:
   - "✅ Connected to server"
   - "✅ Client [id] joined room family-room-demo" ← MUST WAIT FOR THIS
3. THEN send Feishu message
4. Should see: "📩 WebSocket received message:new" in browser console
